# Universal controller layout

Shared identifiers map comparable controls to the same ID across controllers.
The figure shows these assignments for gamepads, sticks, keypads, and peripherals.

![Universal control IDs for gamepads, sticks, keypads, and peripherals](man/figures/universal_buttons_layout.svg)

Each recording contains compact columns for its own controls. Use
`button_layout(movie)` to look up their names and shared IDs, and
`align_buttons()` to align input matrices from different controllers.

The [getting-started guide](README.md#getting-started) shows how to read a recording.

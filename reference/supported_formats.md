# Names of the supported movie file extensions

Names of the supported movie file extensions

## Usage

``` r
supported_formats()
```

## Value

Character vector of file-extensions (lowercase, with leading dot).

## Examples

``` r
supported_formats()
#>  [1] ".fm2"     ".bk2"     ".fcm"     ".lsmv"    ".gmv"     ".vbm"    
#>  [7] ".m64"     ".smv"     ".pxm"     ".pjm"     ".dtm"     ".lmp"    
#> [13] ".fm3"     ".fmv"     ".bkm"     ".tas"     ".tasproj" ".gbmv"   
#> [19] ".mmv"     ".dsm"     ".mc2"     ".mcm"     ".ymv"     ".ctm"    
#> [25] ".gzm"     ".zmv"     ".mar"     ".ltm"     ".wtf"     ".hgm"    
#> [31] ".jrsr"    ".omr"     ".ctas"    ".fbm"     ".dft"    
```

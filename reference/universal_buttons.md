# Universal controller mnemonics

Returns the mnemonic column of [`button_layout()`](button_layout.md). A
movie's compact columns use these registered mnemonics where applicable.
Named source controls use additional mnemonics such as `{key_space}`.
Use [`button_layout()`](button_layout.md) on a movie to obtain its
complete layout.

## Usage

``` r
universal_buttons()
```

## Value

Character vector.
